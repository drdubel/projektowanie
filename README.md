# projektowanie

3D-printable parts, modelled parametrically in [FreeCAD](https://www.freecad.org/) with Python scripts.

## Parts

| Part | Description |
| --- | --- |
| [`esp32c3-supermini-hmmd-case`](parts/esp32c3-supermini-hmmd-case) | Two-part case (base + lid) for an ESP32-C3 SuperMini Plus (red, V2) together with a Waveshare HMMD mmWave sensor. The GPIO header pins stick out through the lid; the sensor's antennas look down through a thin radome floor in the base. |
| [`esp32c3-supermini-case`](parts/esp32c3-supermini-case) | ESP32-only variant of the case, without the sensor bay. Same two-part design with the header pins on top. |

## Layout

Every part has its own folder under `parts/` that holds everything for that part:

```text
parts/<part-name>/
├── <script>.py        parametric FreeCAD script - the source of truth
├── <document>.FCStd   FreeCAD document, generated by the script
└── <export>.stl       export for slicing (where available)
```

All dimensions and tolerances are parameters at the top of each script: change one and re-run to rebuild the model. The script runs its own geometry checks and saves the `.FCStd` only if they all pass. The documents were saved with FreeCAD 1.1.

The STL in `esp32c3-supermini-hmmd-case` contains both bodies, the base and the lid, laid out as in the exploded view (lid above the base). Separate them in your slicer: the base is printed floor-down on a smooth bed (a textured sheet roughens the radome) and the lid top-down.

## Building a part

Open FreeCAD's Python console (View → Panels → Python console) and run the part's script, for example:

```python
exec(open("/Users/antek/projektowanie/parts/esp32c3-supermini-hmmd-case/esp32c3_supermini_case.py").read())
```

The script saves its `.FCStd` next to itself (`SAVE_PATH`). Both the `exec(...)` path above and `SAVE_PATH` are absolute; if you clone the repository somewhere else, update them.

## Adding a part

1. Create `parts/<part-name>/` (lowercase, hyphen-separated).
2. Put the script, the `.FCStd` it writes and any exports (`.stl`, `.step`, ...) in that folder, and point the script's `SAVE_PATH` into it.
3. Add a row to the table above.

FreeCAD backup files (`*.FCBak`) are git-ignored.
